# Скрипты автоматизации препресса для Adobe Illustrator и Photoshop

## Обзор

Этот репозиторий содержит набор JavaScript-скриптов для автоматизации и ускорения препресса в **Adobe Photoshop** и **Adobe Illustrator**. Скрипты предназначены для добавления технологических элементов (тексты в углах, стрелки, линии, крестики, направляющие) и помогают быстрее подготавливать макеты к печати, снижая количество ручных операций.

Репозиторий ориентирован на дизайнеров и препресс-специалистов, работающих с печатной продукцией, большими форматами, вывесками, POS-материалами и техническими макетами.

## Установка скриптов

### Adobe Photoshop

**Windows**

```
C:\Program Files\Adobe\Adobe Photoshop [Версия]\Presets\Scripts\
```

**macOS**

```
/Applications/Adobe Photoshop [Версия]/Presets/Scripts/
```

После копирования перезапустите Photoshop.

### Adobe Illustrator

**Windows**

```
C:\Program Files\Adobe\Adobe Illustrator [Версия]\Presets\[язык]\Scripts\
```

**macOS**

```
/Applications/Adobe Illustrator [Версия]/Presets/[язык]/Scripts/
```

## Скрипты для Adobe Photoshop

### Ps01_text in corners+arrows.jsx

**Назначение**

Добавляет текстовые надписи в четыре угла документа с возможностью автоматического добавления стрелки перед текстом.

**Основные возможности**

* Автоматическое определение размеров документа в миллиметрах
* Отображение информации о документе (имя файла, ширина, высота, DPI)
* Ввод произвольного текста (по умолчанию используется имя файла)
* Настройка высоты текста в мм
* Настройка прозрачности текста
* Опциональное добавление стрелки `↑` перед текстом
* Создание отдельной группы слоёв `↑_text`

**Логика работы**

1. Скрипт временно переключает единицы измерения Photoshop в миллиметры
2. Пользователь настраивает параметры в диалоговом окне
3. Текст размещается в каждом углу с фиксированным отступом (10 мм)
4. После выполнения восстанавливаются исходные настройки единиц измерения

---

### Ps02_lines_steps_and_crosses--AP.jsx

**Назначение**

Создает знаки `+` (кресты) в углах документа для визуального контроля позиционирования и выравнивания.

**Основные возможности**

* Выбор одинаковых или индивидуальных отступов для каждой стороны
* Настройка размера крестика в миллиметрах
* Настройка прозрачности
* Автоматическое размещение крестиков в углах документа
* Создание отдельной группы слоёв `Plus Signs`

**Логика работы**

1. Пользователь задает параметры через диалоговое окно
2. Скрипт рассчитывает координаты углов документа
3. В углах создаются текстовые слои со знаком `+`
4. Вся группа может быть дополнительно смещена для точной подгонки

## Скрипты для Adobe Illustrator

### Ai01_text in corners+arrows.jsx

**Назначение**

Добавляет текстовые надписи в углы артборда Illustrator с поддержкой стрелок и точным позиционированием в миллиметрах.

**Основные возможности**

* Работа с любым артбордом в документе
* Отображение размеров артборда и цветового пространства (RGB / CMYK)
* Использование имени файла или произвольного текста
* Выбор шрифта из установленных в системе
* Выбор углов, в которых будет размещён текст
* Настройка размера шрифта в мм (минимум 4 мм)
* Настройка прозрачности текста
* Опциональное добавление стрелок

**Логика работы**

1. Размеры артборда конвертируются из pt в мм
2. Пользователь задает параметры через диалог
3. Скрипт создает отдельный слой `Text and Arrows Layer`
4. Текстовые объекты точно позиционируются по углам артборда

---

### Ai02_lines_steps_and_crosses.jsx

**Назначение**

Создает вспомогательные линии и крестики на выбранном артборде для препресса и технической разметки.

**Основные возможности**

* Выбор артборда
* Одинаковые или индивидуальные отступы для каждой стороны
* Настройка толщины линий в мм
* Настройка размера крестиков
* Настройка толщины линий крестиков
* Опциональное добавление крестиков в точках пересечения
* Создание отдельных слоёв для линий и крестиков

**Логика работы**

1. Пользователь задает параметры в диалоговом окне
2. Все размеры переводятся из миллиметров в пункты
3. Линии создаются как векторные path-объекты
4. Крестики добавляются на пересечениях направляющих
